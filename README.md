# Rocket Builder 3D｜火箭組裝實驗

一個可直接在手機、iPad 與桌面瀏覽器遊玩的 3D 火箭組裝及飛行物理遊戲。介面採用經典手機火箭模擬器畫風：藍天背景、垂直火箭、左側分類工具列、橫向配件選單及大型升空按鈕。

## 配件系統

遊戲共有 7 個配件分類，每個分類最少 5 款，合共 35 款：

- 火箭頭：標準尖錐、圓頭罩、長流線錐、探測器罩、重型整流罩
- 指令艙：單人、雙人、貨運、科研及深空指令艙
- 燃料箱：短型、標準、長型、低溫及超重燃料箱
- 引擎：單引擎、雙引擎、三聯引擎、真空引擎及五聯引擎
- 助推器：輕型、標準、重型、液體及超重助推器
- 穩定翼：三角翼、梯形翼、後掠翼、格柵翼及大型穩定翼
- 功能配件：降落傘、隔熱盾、著陸支架、太陽能翼及分離環

玩家可以同時安裝多件配件。燃料箱最多 8 件、引擎 5 件、助推器 3 組、穩定翼 4 組、功能配件 8 件；火箭外形和工程數據會即時更新。

## 遊戲內容

- 手機／iPad 觸控旋轉、雙指縮放及左右旋轉按鈕
- 程序生成的火箭、發射台、地面、星空及目標星球
- PBR 金屬材質、ACES 色調映射、動態光照、陰影、火焰及煙霧
- 已安裝配件清單、加減數量、撤銷及重設功能
- 地球軌道返回、月球登陸及火星登陸
- 可調節節流閥及分離助推器
- LOW、HD、MAX 三級畫質與程序音效

## 物理系統

- 推重比 `TWR = thrust / (mass × g)`
- 齊奧爾科夫斯基火箭方程 `Δv = Isp × g0 × ln(m0 / mf)`
- 氣動阻力 `Fd = 0.5 × ρ × v² × Cd × A`
- 高度相關重力及指數大氣密度
- 燃料質量流率、推力、加速度及分級質量變化
- 地球再入熱、降落傘減速、月球／火星動力下降

## 開啟方法

```bash
python3 -m http.server 8080
```

然後瀏覽 `http://localhost:8080`。Three.js 透過 CDN 載入，首次開啟需要網絡連線。

## 自動驗證

```bash
npm run check
```

驗證會重新合併及解壓遊戲程式，檢查 JavaScript 語法、七個分類是否各有最少五款配件、多配件組裝及飛行物理標記。

此專案適合教學與遊戲體驗，並非真實航空工程或安全認證工具。
