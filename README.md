# Rocket Lab 3D｜火箭星空實驗室

一個可直接在手機、iPad 與桌面瀏覽器遊玩的 3D 火箭科學實驗遊戲。玩家可自行選擇配件、組裝火箭、檢查工程數據，並挑戰地球軌道返回、月球登陸或火星登陸。

## 已完成的遊戲內容

- 手機／iPad 觸控操作，支援旋轉、縮放及橫直畫面
- 程序生成的地球、月球、火星、雲層、星空與發射台
- PBR 材質、ACES 色調映射、動態光照、陰影及大氣輝光
- 火箭配件組裝及拆除：整流罩、指令艙、燃料箱、主引擎、助推器、尾翼、隔熱盾、降落傘、著陸支架、太陽能翼
- 即時計算總質量、推重比、理論 Δv、穩定性、阻力及任務條件
- 升空物理：高度相關重力、大氣密度、氣動阻力、動壓、燃料流量、推力、加速度與結構完整度
- 可調節節流閥、分離助推器／整流罩、展開降落傘及執行自動降落
- 三條任務流程：地球軌道返回、月球軟著陸、火星軟著陸
- 自動畫質調節、程序音效及 PWA 安裝資訊

## 開啟方法

這是純靜態網站，可用任何靜態伺服器開啟，例如：

```bash
python3 -m http.server 8080
```

然後瀏覽 `http://localhost:8080`。

> 由於 Three.js 與 cannon-es 透過 CDN 載入，首次開啟需要網絡連線。

## 科學模型說明

遊戲採用真實公式的縮放模擬，包括：

- 推重比 `TWR = thrust / (mass × g)`
- 齊奧爾科夫斯基火箭方程 `Δv = Isp × g0 × ln(m0 / mf)`
- 氣動阻力 `Fd = 0.5 × ρ × v² × Cd × A`
- 指數大氣密度模型與隨高度變化的地球重力
- 推力／比衝推算燃料質量流率

此專案適合教學與遊戲體驗，並非真實航空工程、任務設計或安全認證工具。
